# GIFメーカー
動画・写真(複数)・PDFを、大きさを指定してGIFにするアプリ(FastAPI + ffmpeg)。

## Renderに公開する手順
1. このフォルダをGitHubの新しいリポジトリにアップロードする
2. Renderで New > Blueprint を選び、そのリポジトリを指定する(render.yamlが読まれる)
3. 求められる環境変数 APP_PASSWORD に、自分だけが知るパスワードを入れる
4. デプロイが終わったらURLを開く(ユーザー名は何でもよく、パスワードだけ照合される)

## メモ
- 無料枠は、使わないと止まり、次の起動に1分ほどかかる
- アップロードは150MBまで(環境変数 MAX_UPLOAD_MB で変更可)。動画は最大120秒まで
- 変換後のファイルはサーバーに残らない
- ローカルで試す: docker build -t gif . && docker run -p 10000:10000 gif
